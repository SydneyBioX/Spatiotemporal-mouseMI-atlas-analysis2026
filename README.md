# Spatiotemporal-mouseMI-atlas-analysis2026

Analysis of spatiotemporal mouse heart data generated with Cartana spatial transcriptomics technology. This analysis supports a publication.

GenePanel_Analysis_Scripts: this contains scripts for gene panel design & simulations.

Data_Analysis scripts:

- Defining zones
- Identifying fibrotic programs
- Predicting CF states
- Identifying specific immune subpopulations
- Visium perturbation data analysis

Figure_Scripts: this contains scripts for all main text and extended figures.
