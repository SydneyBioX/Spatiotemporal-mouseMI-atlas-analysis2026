# Spatiotemporal-mouseMI-atlas-analysis2026
Analysis of spatiotemporal mouse heart data generated with Cartana spatial transcriptomics technology. This analysis supports a publication.

Analysis script order:

1. Gene panel design & QC
2. Segmentation
3. Spatial data QC
4. Clustering & Annotation
5. Defining zones (Define_zones.R)
6. Identifying fibrotic programs (Fibrotic_programs.R)
7. Predicting CF states (CF_states.R)
8. Visium perturbation data analysis (Visium_perturb_data.R)
